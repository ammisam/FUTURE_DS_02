# FUTURE_DS_02: Customer Retention & Churn Analysis

## Internship
**Organization:** Future Interns  
**Domain:** Data Science & Analytics  
**Task:** Task 2 – Customer Retention & Churn Analysis

## 1. Project Overview
Customer churn occurs when customers stop using a company's products or services. This project analyzes customer data to understand churn patterns, identify customer segments associated with higher churn, and develop recommendations to improve customer retention.

The project uses Power BI to visualize customer behavior and present business insights through an interactive dashboard.

## 2. Project Objectives
- Analyze customer churn and retention patterns.
- Identify churn trends across different contract types.
- Understand the relationship between customer tenure and churn.
- Analyze customer monthly charges and payment methods.
- Identify customer segments that may require retention strategies.
- Recommend actions to improve customer loyalty and reduce churn.

## 3. Dataset Description
**Dataset:** `telco_churn_unclean.csv`

The dataset contains 7,048 records and 21 columns.

Important attributes include:
- Customer ID
- Gender
- Senior Citizen
- Partner and Dependents
- Tenure
- Phone Service and Internet Service
- Online Security and Technical Support
- Contract Type
- Paperless Billing
- Payment Method
- Monthly Charges
- Total Charges
- Churn Status

## 4. Tools and Technologies
- Microsoft Power BI – Dashboard development and visualization
- CSV Dataset – Customer data source
- Data Analysis – Customer segmentation and churn analysis
- GitHub – Project documentation and version control

## 5. Project Workflow
1. Import the customer churn dataset.
2. Inspect data quality and identify missing or inconsistent values.
3. Clean and prepare the data for analysis.
4. Develop measures for customer count, churn rate, retention rate, and average tenure.
5. Analyze churn across contract types, tenure groups, and payment methods.
6. Create visualizations and an interactive Power BI dashboard.
7. Interpret the results and develop business recommendations.

## 6. Key Performance Indicators (KPIs)
- Total Customers
- Churned Customers
- Customer Churn Rate
- Customer Retention Rate
- Average Customer Tenure
- Average Monthly Charges

## 7. Dashboard Insights
The dashboard is intended to help analyze:
- Customer churn patterns
- Churn across contract categories
- Customer tenure and retention trends
- Churn by payment method
- Customer charges and service usage
- Customer segments requiring retention attention

Actual findings and numerical results should be added after validating the completed dashboard.

## 8. Business Recommendations
Based on the analysis findings, potential strategies include:
- Improve onboarding and engagement for new customers.
- Review customer concerns associated with high-churn contract categories.
- Investigate payment-related difficulties.
- Evaluate pricing and suitable subscription plans.
- Develop targeted retention campaigns for at-risk customer segments.
- Monitor churn and retention KPIs regularly.

These recommendations should be prioritized according to the actual analysis results.

- Data-driven business recommendations

This project demonstrates how customer data analysis and business intelligence can support customer retention decisions. The dashboard helps organize churn-related information, identify patterns, and guide further investigation into customer loss.
